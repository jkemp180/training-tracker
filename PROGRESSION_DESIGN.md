# Automatic progression

Each strength exercise has a prescribed set sequence. Sets may use the same load or ramp across the exercise, for example 70 kg x 8, 75 kg x 6, and 80 kg x 5.

Normal use requires only tapping completed sets. When every prescribed set is completed, the next occurrence increases each weighted set by the exercise-specific increment. If any set is missed, the same prescription repeats.

Manual adjustment is available only as an exception and is not part of the normal workout flow.
